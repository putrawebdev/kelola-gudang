# Kelola Gudang – Frontend (Laravel 12)

File di zip ini hanya bagian frontend. Salin ke project Laravel 12 kamu:

1. Buat project: `composer create-project laravel/laravel kelola-gudang`
2. Salin folder `public/` dan `resources/views/` ke project (timpa jika diminta).
3. Salin isi `routes/web.php` ke `routes/web.php` project.
4. Jalankan `php artisan serve`, buka http://127.0.0.1:8000

Background memakai `public/images/gudang.jpg`.
Font & ikon dimuat dari CDN (Google Fonts, Bootstrap Icons) jadi butuh internet.
Data di tabel masih dummy di dalam file Blade; tombol hapus/simpan hanya tampilan.
